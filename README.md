# MovieExpert API

**MovieExpert** — это интеллектуальная бэкенд-система для подбора фильмов, построенная на принципах классического искусственного 
интеллекта (продукционных правил). В отличие от простых фильтров, система имитирует логику живого эксперта-киноведа.

## Ключевые особенности
* **Логический движок (Experta)**: Использует базу знаний и систему вывода для анализа предпочтений пользователя.
* **Динамический расчет "Understanding Level"**: Система в реальном времени вычисляет, насколько хорошо она понимает запрос (в процентах), учитывая полноту ответов.
* **Контроль согласованности (Consistency Check)**: Алгоритм выявляет логические противоречия в ответах и корректирует точность рекомендаций.
* **Smart Skip Logic**: Автоматический пропуск вопросов. Если система может логически вывести ответ из предыдущих данных, она делает это сама.
* **Многоэтапный процесс (Stages)**: Опрос разбит на 7 логических блоков: от эмоций до технических деталей (длительность, рейтинг).

## Технологический стек

*   **Язык:** [Python 3.8+]
*   **Фреймворк:** [Flask]
*   **Движок правил:** [Experta] (аналог CLIPS для Python)
*   **Интерфейс:** RESTful API с поддержкой CORS.

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install flask flask-cors experta
```

### 2. Подготовка данных
Убедитесь, что в корне проекта находится файл films.json. Пример структуры:

```json

{
  "films": [
    {
      "id": 1,
      "title": "Начало",
      "genres": ["science fiction", "thriller"],
      "features": { "is_thought_provoking": true, "has_plot_twist": true },
      "rating": 8.8,
      "duration": 148
    }
  ]
}
```

### 3. Запуск сервера
```bash
python app.py
```
Сервер запустится на http://localhost:5000.

## Документация API
| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/start` | Инициализация новой сессии. Возвращает `session_id`. |
| `GET` | `/api/question` | Получить следующий актуальный вопрос (принимает `session_id`). |
| `POST` | `/api/answer` | Отправить ответ на текущий вопрос. |
| `GET` | `/api/recommendations/{id}` | Получить финальный топ-3 рекомендаций. |
| `GET` | `/api/status/{id}` | Текущий статус: прогресс и уровень понимания. |
| `POST` | `/api/reset/{id}` | Сброс данных текущей сессии. |

Пример ответа на вопрос (JSON)

```json
{
  "answer": true,
  "question_key": "wants_thoughtful",
  "session_id": "your-uuid-here"
}
```

## Как работают рекомендации?

Рекомендательная система работает в два этапа:
1. Inference (Вывод): На основе ответов активируются правила (Rules). Например:
    * ЕСЛИ пользователь хочет задуматься И выбрал драму, ТО добавляется условие philosophical с весом 1.5.
2. Scoring (Скоринг): Каждый фильм из базы проходит через систему фильтров. За каждое совпадение с активированным условием фильм получает баллы. В итоге пользователь получает фильмы с наивысшим баллом.
